# Welcome to OpenMCP

OpenMCP is the open-source registry and marketplace for Model Context Protocol (MCP) servers and AI tools.

## The Ecosystem

OpenMCP consists of four primary pillars:

1. **The Registry API**: A secure FastAPI backend handling package publishing and authentication.
2. **The Web Marketplace**: A beautiful UI for discovering AI tools globally.
3. **The Developer CLI**: `openmcp` command-line tool for publishing and installing packages.
4. **The Python SDK**: `openmcp-sdk` library to build MCP servers effortlessly with decorators.

## Quick Start

### Install the CLI
```bash
pip install openmcp-cli
```

### Install the SDK
```bash
pip install openmcp-sdk
```

Check out the [Getting Started](getting-started.md) guide to build your first AI tool!
